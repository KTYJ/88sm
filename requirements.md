# Database Project Requirements

## 4. Queries
- Produce queries to extract relevant information for decision making.  
- **Single table queries are not allowed.**  
- Use multiple tables and aggregate functions where necessary.  
- Judge based on usefulness and complexity of queries.  
- Incorporate views where appropriate.  
- **Each student must produce 2 queries.**  
- Queries must address informational needs at all levels:
  - Strategic
  - Tactical
  - Operational

---

## 5. Stored Procedures
- Design and create stored procedures for various use case scenarios.  
- **Each student must produce 2 stored procedures.**  
- Procedures may include:
  - Data retrieval (Selection with/without cursor)
  - Data manipulation (Add, Update, Delete)
  - Validation

---

## 6. Triggers
- Design and create triggers to enforce system-wide **business rules and policies.**  
- **Each student must produce 2 triggers.**

---

## 7. Reports
- Write procedures to generate reports:
  - Summary
  - Detail
  - On-demand basis (parameter values may be passed during call)  
- **Each student must produce 2 reports.**  
- Use cursors in report generation (nested cursor preferred).  
- Marking scheme:
  - Single cursor: ~6 marks
  - Multiple cursor: ~7 marks
  - Nested cursor: ~8 marks

---

## 8. Extra Effort Items
Each student must incorporate:
- 1 sequence  
- 2 views (for both queries)  
- 2 indexes  
- 2 output formatting (for both queries)  
- 2 exceptions (different types: `RAISE_APPLICATION_ERROR`, default exception, custom exception, or `PRAGMA EXCEPTION_INIT`)  
- Functions when necessary  

**Scoring:** 2 marks for each correct extra effort item.

---

## 9. Presentation and Participation
- Demonstration and explanation of tasks (Task 4–8)  
- Q & A session  
- Active participation in class discussion
